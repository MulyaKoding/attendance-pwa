# Attendance App

Aplikasi absensi (clock in/out) berbasis web — PWA untuk karyawan melakukan presensi harian.

## Tech Stack

- **[Next.js](https://nextjs.org)** (App Router) — framework React
- **TypeScript** — type safety
- **Tailwind CSS** — styling
- **[Zustand](https://github.com/pmndrs/zustand)** (dengan `persist`) — state management & auth session
- **[SWR](https://swr.vercel.app)** — data fetching & caching
- **[React Hook Form](https://react-hook-form.com)** + **[Zod](https://zod.dev)** — form handling & validasi

## Getting Started

Jalankan development server:

```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

## Deploy

Deploy menggunakan [Vercel Platform](https://vercel.com/new).
